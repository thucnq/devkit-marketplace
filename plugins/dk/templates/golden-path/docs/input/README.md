# Đầu vào cho /dk:spec

Bỏ nguyên liệu thô vào đây trước khi chạy `/dk:spec docs/input/`.

| File | Nội dung |
|---|---|
| `ghi-chu-hop.md` | Những gì khách đã nói qua chat, gọi, họp — càng nguyên văn càng tốt |
| `hang-muc.csv` | Danh sách hạng mục đã báo giá (nếu đã có báo giá) — `/dk:spec` sẽ giữ phạm vi đúng bằng danh sách này |
| `*.pdf`, `*.docx`, ảnh | Tài liệu khách gửi |
| `misa/`, `client-data/` | File dữ liệu mẫu của khách, **đã xóa/đổi số liệu thật**. Không commit (đã có trong `.gitignore`) |
